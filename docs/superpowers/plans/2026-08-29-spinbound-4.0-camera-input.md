# SPINBOUND 4.0 Bird's-eye Camera & Input Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the approved high bird's-eye default camera with free orbit/zoom, Classic View, Tactical View, occlusion protection, and camera-relative desktop/mobile controls without changing authoritative gameplay outcomes.

**Architecture:** Camera math is split into a pure testable yaw-to-XZ movement mapper and Unity presentation rigs. `UnityRotorGameHost` reads device intent, maps screen direction through the current gameplay camera yaw, then sends only world XZ intent into Core. Camera state never enters the authoritative stage simulation.

**Tech Stack:** Unity Input System 1.14.2, URP 17.3.0, pure Core math for yaw mapping, NUnit EditMode + PlayMode tests.

**Spec:** `docs/superpowers/specs/2026-08-29-spinbound-4.0-design.md`

## Global Constraints

- Recommended gameplay pitch baseline: 78 degrees.
- Initial perspective FOV range: 30–34 degrees; use 32 degrees as the first tuned default.
- Legal pitch: 35–88 degrees; yaw: 360 degrees; zoom: 0.65x–1.6x.
- RMB drag = orbit; mouse wheel = zoom; Q/E = yaw; Home = reset.
- W/Up, S/Down, A/Left, D/Right are always screen-relative.
- Gameplay camera never follows rotor rotation and never auto-yaws toward movement.
- Tactical View pauses simulation and timer.
- Occlusion protection covers the full rotor plus endpoint safety margin.
