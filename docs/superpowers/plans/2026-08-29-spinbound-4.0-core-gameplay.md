# SPINBOUND 4.0 Core Gameplay Rebuild Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the 3.0 checkpoint/collision model with a deterministic 4.0 rotating-bar simulation that reproduces the important timing, speed, collision-response, heart, zone, and spring behavior while deliberately excluding original-game glitches.

**Architecture:** `Spinbound.Core` remains Unity-engine-free and authoritative. Input produces a normalized screen-relative movement intent plus two accelerator buttons; simulation advances at 120 Hz; collision produces a manifold; gameplay applies deterministic bump/angular response, damage/penalty, zones, and spring events. `Spinbound.UnityRuntime` only adapts Unity input/time and presents immutable snapshots.

**Tech Stack:** Pure C#/.NET types inside `Spinbound.Core`, `System.Numerics`, NUnit EditMode tests, Unity 6000.3.18f1 integration host.

**Spec:** `docs/superpowers/specs/2026-08-29-spinbound-4.0-design.md`

## Global Constraints

- Fixed step: 120 Hz.
- Base angular speed: 60 deg/s magnitude.
- Movement ratios: Speed1 1.0x, Speed2 1.5x, Speed3 2.0x.
- Normal half-length: retain 1.44 m baseline; Assist half-length: retain 1.08 m baseline until playtest tuning; motion tuning is identical between modes.
- Collision penalty: +3.00 s per damaging hit.
- Hearts: 3; zero hearts fails.
- Damage invulnerability reference: 20 original 60 Hz frames = 1/3 s = 40 authoritative 120 Hz ticks.
- Reference-inspired wall response baseline: angular collision magnitude ratio `1024/182` of base angular speed; return step ratio `91/182` per original 60 Hz frame; bump speed ratio `2/1.5` of Speed1; bump decay `0.75` per original 60 Hz frame.
- At 120 Hz, bump decay per tick is `sqrt(0.75)` so two ticks equal one original-frame decay.
- Do **not** reproduce unsigned-coordinate overflow, wall clipping, center-wall 4 px/frame wall-grind exploit, or out-of-bounds replication bugs.

```csharp
public enum SpeedTier : byte { Speed1 = 0, Speed2 = 1, Speed3 = 2 }
public enum RotorMode : byte { Standard = 0, Assist = 1 }
public enum RotationDirection : sbyte { Clockwise = -1, CounterClockwise = 1 }

public static class RotorTuning
{
    public const int FixedHz = 120;
    public const float FixedDeltaSeconds = 1f / FixedHz;
    public const float BaseAngularSpeedDegPerSecond = 60f;
    public const float Speed1MetersPerSecond = 2.2f;
    public const float Speed2MetersPerSecond = Speed1MetersPerSecond * 1.5f;
    public const float Speed3MetersPerSecond = Speed1MetersPerSecond * 2f;
    public const float StandardHalfLengthMeters = 1.44f;
    public const float AssistHalfLengthMeters = 1.08f;
    public const float RadiusMeters = 0.16f;
    public const float CollisionAngularMagnitudeDegPerSecond =
        BaseAngularSpeedDegPerSecond * (1024f / 182f);
    public const float AngularRecoveryDegPerSecondSquared =
        BaseAngularSpeedDegPerSecond * (91f / 182f) * 60f;
    public const float CollisionBumpMetersPerSecond =
        Speed1MetersPerSecond * (2f / 1.5f);
    public const float BumpDecayPerTick120Hz = 0.8660254038f;
    public const int DamageInvulnerabilityTicks = 40;

    public static float SpeedFor(SpeedTier tier) => tier switch
    {
        SpeedTier.Speed1 => Speed1MetersPerSecond,
        SpeedTier.Speed2 => Speed2MetersPerSecond,
        SpeedTier.Speed3 => Speed3MetersPerSecond,
        _ => Speed1MetersPerSecond,
    };
}
```

```csharp
public static RotorState IntegrateFree(in RotorState s, in RotorIntent intent, float dt)
{
    var move = RotorMath.NormalizeMove(intent.MoveDirection);
    var inputVelocity = move * RotorTuning.SpeedFor(intent.SpeedTier);
    var position = s.Position + (inputVelocity + s.BumpVelocity) * dt;
    var angle = RotorMath.Wrap360(s.AngleDeg + s.AngularVelocityDegPerSecond * dt);
    var targetAngular = (float)s.DefaultDirection * RotorTuning.BaseAngularSpeedDegPerSecond;
    var angular = RotorMath.MoveToward(s.AngularVelocityDegPerSecond, targetAngular,
        RotorTuning.AngularRecoveryDegPerSecondSquared * dt);
    var bump = s.BumpVelocity * RotorTuning.BumpDecayPerTick120Hz;
    if (bump.LengthSquared() < 1e-8f) bump = Vector2.Zero;
    return s.With(position: position, angleDeg: angle, angularVelocity: angular, bumpVelocity: bump);
}
```
